# A/B 测试主持清单（给自己看的一页纸）

## 开始前（只做一次）
1. 打开**测试专用服务器**（单独的数据库，重置它不会动你自己的小镇）：
   ```bash
   cd future-feed && PORT=8002 FUTUREFEED_DB=data/study.db .venv/bin/python app.py
   ```
2. 浏览器打开 **http://localhost:8002/research**（主持台）。如果页面顶部出现**红色警告**，说明开错了服务器，别点 Reset。
3. 先自己完整跑一遍当练习（不计入结果），顺便计时。

## 每位参与者（约 15 分钟）
1. 主持台自动填好编号（P1、P2…）。**单号先 A 后 B，双号先 B 后 A**，页面会写明顺序。
2. 念开场白（主持台上有原文）：没有标准答案，诚实的批评最有用，选一个真心想坚持的习惯。
3. **每一轮**：
   - 点 **Reset app** → 点 **Open A/B in new tab**
   - B 版：先有 3 页小故事，注册后有 6 步导览，**让他们自己看，你别讲解**
   - 两轮都用**同一个习惯**，从列表里选，别用 "Something else"（省时间、省 AI 用量）
   - 他们**按住** "Hold to check in"（第 1 天）
   - 你点底部黑条 **Next day →**，他们再打卡（第 2 天）
   - 你点 **Skip 4 days ⏭**，让他们反应。B 版会出现"暴风雨"和一张担心的明信片，**页面要等约 20 秒**，提前说一句"它在写"
   - 他们再打卡一次
   - 说"随便看看，看完告诉我"，**点 Start timer**，结束时把秒数填进去
   - 把电脑交给他们填这一轮的 5 道题 → **Save round**
4. 两轮都做完：他们填最后的问题，你写观察笔记 → **Save final answers** → **Next participant →**

## 记下来（报告要用）
- 原话反应，例如"哇""有点吓人""这什么意思"
- 哪里卡住或看不懂
- 有没有翻转明信片、点进楼里、玩季节/太阳/树
- 看到"暴风雨"时的反应

## 结束后
- 主持台底部 **Download CSV**，得到所有答案（报告的表格和图表从这里来）
- 目标 5–8 人；时间紧的话 5 个人也够做描述性对比

## 小提醒
- 每次 B 版打卡 8–16 秒（AI 在写明信片），正常
- 自己的小镇照常在 8000 端口用，两个服务器互不影响
